# ScrollRect and Responsive Integration

## Responsive profiles

`TaffyLayoutGroup.responsiveProfiles` is evaluated against the current layout rect. A profile has min/max width/height bounds, priority, and opt-in overrides for container display, Flex direction/wrap/gaps/alignment, Grid auto-flow, and padding.

At runtime you can force a named profile:

```csharp
if (!group.SetRuntimeResponsiveProfile("Compact", out string error))
    Debug.LogWarning(error);
```

Call `ClearRuntimeResponsiveProfile()` to resume automatic breakpoint selection.

## Safe area

Set `safeAreaMode = TaffySafeAreaMode.Padding` to convert `Screen.safeArea` into local padding. For tests or platform-specific control you can call `SetRuntimeSafeAreaInsets(...)`, then `ClearRuntimeSafeAreaInsets()` when the override is no longer needed.

## Pixel rounding

`pixelRounding` supports None, Round, Floor, Ceil, and CanvasPixel. `CanvasPixel` rounds in scaled Canvas pixel space.

## ScrollRect content bridge

When a `TaffyLayoutGroup` is the `ScrollRect.content`, `scrollRectContentMode = AutoExpandContent` lets Taffy expand the scrolling content on enabled scroll axes from its preferred layout size.

The bridge yields an axis to an enabled `ContentSizeFitter` that owns that axis. If an `AspectRatioFitter` owns the ScrollRect content size, Taffy yields automatic expansion to avoid a rebuild loop.

## Rebuild-loop protection

`maxRebuildRequestsPerFrame` caps repeated dirty requests generated by integration feedback. `SuppressedRebuildRequestCount` exposes suppressed requests; call `ResetRebuildDiagnostics()` after investigating.

Use `GetIntegrationWarnings()` or the Layout Debugger to see detected ScrollRect, ContentSizeFitter, and AspectRatioFitter ownership conflicts.

## Recommended pattern

Let Taffy own layout geometry, let ScrollRect own scrolling, and give ContentSizeFitter/AspectRatioFitter only axes that Taffy is explicitly configured to yield. This avoids competing layout controllers and nondeterministic rebuild chains.
