# TaffyUGUI

Responsive Flexbox and Grid layout engine for Unity uGUI, powered by Rust and [Taffy](https://github.com/DioxusLabs/taffy), while Unity keeps rendering, interaction, prefabs, TextMeshPro, ScrollRect, and EventSystem.

## Status

Early development. The repository currently provides the native Rust bridge, Unity package scaffolding, Flexbox-facing runtime components, CI, and cross-platform build scripts. Grid and release binaries will be added after the Flexbox ABI is validated across
